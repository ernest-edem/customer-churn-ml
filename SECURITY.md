# Security Policy

## Supported Versions

This project is maintained as a portfolio and educational machine learning project.

Security fixes will generally be applied to the latest version of the project on the `master` branch.

Older versions may not receive security updates.

## Reporting a Security Issue

If you discover a potential security vulnerability in this project, please do not disclose sensitive details publicly through GitHub Issues.

Instead, contact the project maintainer privately through the contact information provided in the repository owner's GitHub profile.

When reporting an issue, please include:

* A clear description of the vulnerability.
* The affected file, component, or functionality.
* Steps to reproduce the issue.
* The potential impact.
* Any suggested mitigation, if available.

Please allow reasonable time for the issue to be reviewed before publicly disclosing the vulnerability.

## Scope

This policy applies to the source code and configuration contained in this repository.

It does not cover:

* Third-party services or infrastructure.
* External datasets.
* User devices or local environments.
* Dependencies maintained by other projects.

Security issues in third-party dependencies should be reported to their respective maintainers when appropriate.

## Responsible Disclosure

Please avoid publicly sharing credentials, API keys, personal information, exploit code targeting real systems, or other sensitive information when reporting an issue.

Thank you for helping improve the security and reliability of this project.
